## Problem

LearnHub wore the fleet's instrument look: zinc ground, one bright blue, Geist at 12–14px,
the shared two-tier header. v0.28.0 warmed the page but kept the fleet header, so every
screen showed two palettes. The human asked on 2026-11-09 to overhaul the UI and leave the
fleet's design. They compared four style directions and three layouts on a canvas
(https://claude.ai/artifact/E4AQgKt4SmVo8TUspL2iA1) and chose:

- **Palette:** A, "Study Hall", dark mode only.
- **Layout:** "The Desk" for a course. That is the next cycle, v0.30.0.
- **Landing page:** the current Library, restyled.

Opened although 'Competency' holds the focus: the human said to open it anyway (2026-11-09).

## Review

**What did the plan miss?** That the accent was overloaded. Once the accent turned warm, "Ready"
chips on every card competed with the one real call to act. The old blue hid that. The sideways
reader scroll was older than this cycle and only showed because the window sat just above the
1440 threshold.

**What did the agent need that the prompt did not give?** That `render_agent_docs.py` has no
`--help`. Any script that writes across repos should be read before it is run.

**What did I learn?** A style change is cheap when the tokens are clean: about 25 lines of values
repainted every screen. The layout (the Desk) is where the real work is, and it gets its own cycle.

Decision: ship. Next: v0.30.0 The Desk.
